# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Cenovus Supply Chain & Operations Analytics project.

## Dashboard Objectives

The dashboard will provide insights into:

- Production performance and operational trends.
- Facility and capacity utilization.
- Transportation and logistics performance.
- Delivery delays and transportation bottlenecks.
- Supply chain and operational KPIs.
- Relationships between production activities and logistics performance.

## Folder Structure

- `dashboard/` — Stores the Power BI `.pbix` dashboard file.
- `screenshots/` — Stores screenshots of dashboard pages and visualizations.

**Tools:** Power BI Desktop, Power Query, and DAX.

The dashboard will communicate analytical findings through interactive visualizations and performance indicators.
