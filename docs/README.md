# Project Documentation

This folder contains supporting documentation for the Cenovus Supply Chain & Operations Analytics project.

## Planned Documentation

1. `data_sources.md` — Describes the sources, origins, and collection methods of the datasets.
2. `data_dictionary.md` — Defines dataset columns, data types, and their meanings.
3. `kpi_definitions.md` — Documents the formulas, definitions, and business relevance of the project KPIs.

This documentation supports transparency, reproducibility, and a clear understanding of the analytical process.
