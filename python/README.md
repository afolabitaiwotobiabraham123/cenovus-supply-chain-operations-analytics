# Python Analysis

This folder contains the Python and Jupyter Notebook workflows used to acquire, explore, assess, clean, and prepare data for the Cenovus Supply Chain & Operations Analytics project.

## Planned Notebooks

1. `01_data_acquisition.ipynb` — Collect data from selected public sources or load simulated datasets.
2. `02_exploratory_data_analysis.ipynb` — Explore production, transportation, logistics, and supply chain data.
3. `03_data_quality_assessment.ipynb` — Assess missing values, duplicates, inconsistencies, and data validity.
4. `04_data_cleaning_and_preparation.ipynb` — Clean, transform, and prepare datasets for analysis.

**Tools:** Python, Jupyter Notebook, Pandas, and Matplotlib.

The notebooks will document each stage of the data preparation and analysis workflow.
