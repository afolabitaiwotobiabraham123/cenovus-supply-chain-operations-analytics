# Forecasting Analysis

This folder contains forecasting models developed to support production planning, operational decision-making, and supply chain performance analysis for the Cenovus project.

## Planned Forecasting Notebooks

1. `01_production_volume_forecasting.ipynb` — Forecast future production volumes using historical production data.
2. `02_transportation_demand_forecasting.ipynb` — Forecast transportation and logistics requirements based on available historical data.
3. `03_capacity_utilization_forecasting.ipynb` — Estimate future facility or transportation capacity utilization where sufficient data is available.
4. `04_forecast_evaluation.ipynb` — Evaluate forecasting performance using appropriate metrics and compare predicted values with actual observations.
5. `05_material_demand_forecasting.ipynb` - This will forecast future demand for operational materials, spare parts and maintenance supplies, provided the data supports it.

## Tools

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn
- Statsmodels

## Purpose

Forecasting will help identify potential changes in production and logistics requirements, support capacity planning, and improve operational decision-making.

**Note:** Forecasting models will only be developed where the available data has sufficient historical observations and suitable variables. Forecast results will be evaluated before business recommendations are made.
