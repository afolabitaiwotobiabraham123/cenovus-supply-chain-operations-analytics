# MySQL Analysis

This folder contains SQL scripts used to store, query, analyze, and evaluate the supply chain and operational data for the Cenovus project.

## Planned SQL Scripts

1. `01_database_setup.sql` — Create the database and required tables.
2. `02_production_operations_analysis.sql` — Analyze production performance and operational trends.
3. `03_transportation_logistics_analysis.sql` — Analyze transportation and logistics performance.
4. `04_operational_kpi_calculations.sql` — Calculate and evaluate key operational performance indicators.
5. `05_supply_chain_operations_analysis.sql` — Investigate relationships between production, transportation, and supply chain performance.

**Tools:** MySQL.

SQL analysis will focus on structured queries, performance measurement, operational comparisons, and business insights.
